# Nordlicht Operations – synthetischer Entwicklungsstand

Fiktive mandantenfähige Warenwirtschaft. Keine echten Kunden, Zahlungen oder Versandaktionen.

Die Module sind kleine Beispielimplementierungen, kein lauffähiges SaaS-Produkt. Ein Test im Repository ist kein Nachweis, dass er ausgeführt wurde. Es gibt bewusst offene Implementierungsfragen.

Tests: `python -m pytest tests` (pytest muss bereits vorhanden sein). Keine CI-Ergebnisse oder Produktionsfreigabe enthalten.

Siehe [Quellenbezüge](docs/traceability.md).
